# IDEA BACKLOG

Идеи отсортированы по ожидаемой ценности, а не по эффектности названия.

## Now — доказать текущую игру

1. **Play Solo evidence pass.** Boot handoff, First Miracle, два последовательных
   capture, Secret Frame, один полный активный раунд, respawn и clean Stop.
2. **Server & Clients ×4.** City Pulse, role coordination, simultaneous discovery,
   late join, disconnect и friend encore.
3. **Mobile/gamepad matrix.** 360×800, 800×360, tablet, 1280×720, gamepad; touch
   targets, safe area, camera, prompts, large text/reduced effects.
4. **Boot/world profile.** Измерить click-to-controllable, server world-build,
   client App init, first snapshot и first world reaction.
5. **10–20 no-coaching sessions.** Найти первый массовый момент непонимания.

## Next — только после evidence

1. **Friend Encore contract.** Сохранение состава и мгновенное подтверждение всей
   группе, если 4-client тест показывает friction.
2. **One-district production kit.** Один модульный mesh/material/audio slice с
   owner/license/fallback; сравнить memory и visual clarity до масштабирования.
3. **Secret Frame delight pass.** Короткое camera framing/caption только если ручной
   тест докажет, что текущий reveal слишком слаб; обязательно respect reduced motion.
4. **First-goal experiment.** Одно A/B изменение copy или framing после появления
   baseline, не одновременно с reward/timing.
5. **World boot decomposition.** Chunked/lazy creation только если профиль покажет,
   что synchronous build реально портит join time.

## Later — системные возможности

- редкие cooperative district encounters, комбинирующие две существующие mechanics;
- сезонные visual modifiers как data-only manifest, без новых валют;
- spectator reactions с positive allowlist;
- коллекционные camera treatments, открываемые Secret Frames;
- party-aware queue/teleport после доказанной аудитории;
- creator-made curated briefs только с полноценной moderation pipeline.

## Не строить сейчас

- новую валюту или второй battle pass;
- generative text в player-facing UI;
- beauty/body score и токсичный рейтинг;
- платный progression skip;
- глобальный trading без fraud/data design;
- ML-рекомендатель без достаточного объёма данных;
- переписывание World/App «ради архитектуры»;
- тяжёлые per-frame эффекты или experimental APIs без fallback.
